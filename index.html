日本假期提醒

10/5～10/12 期間，日本只有一個國定假日：10/12（一）體育之日（スポーツの日），恰逢回程當天，並與週末（10/10、10/11）連成三天連假。 10/10～10/12 熱門景點與交通會比平日擁擠，回程當天建議提早前往成田機場。

D2

10/6（二）淺草美食日

交通

錦絲町 → 淺草：總武線轉乘或都營淺草線直達，車程約15-20分。

行程時間軸

  • 上午淺草寺、雷門、仲見世通
  • 午餐天婦羅 大黒家 本店（招牌4尾炸蝦天丼，約¥2,000-3,000/人）只收現金，不接受訂位，用餐時間常大排長龍，記得帶現金
  • 午後淺草寺周邊散策 → とんかつ 夏の家（炸豬排定食，可外帶小點心）
  • 下午2點前壽壽喜園 淺草本店（七種濃度抹茶冰淇淋）整理券常在下午2點前（假日甚至中午）發完，建議中午後儘早前往排隊
  • 可選加碼谷根千（谷中銀座）／晴空塔／上野公園
D3

10/7（三）鎌倉一日遊

交通

錦絲町 → 東京站轉JR橫須賀線直達鎌倉，車程約1小時內。

行程時間軸

  • 上午鶴岡八幡宮
  • 上午～中午高德院大佛（江之電或步行前往）
  • 13:15稲村崎Yoridocoro（已訂位，定食套餐）待確認：訂位表單是否完整選好定食項目、¥1,000/人是否為座位費（單獨於餐費之外）
  • 下午由比濱海灘
  • 選配江之島延伸行程（視體力調整）
參考：本人已於9/13（日）進行個人踏查，走訪高德院大佛、長谷寺、鶴岡八幡宮，人潮尚可，比印象中多年前的舊經驗好很多；踏查期間於藤澤住2晚單人房（東京週末住宿較貴，作為替代方案）。
D4

10/8（四）箱根一日遊

交通與票券

錦絲町 → 新宿轉小田急浪漫特快直達箱根湯本。

從錦絲町到新宿比原先「上野出發」多一段轉乘，建議比原訂時間表多預留15-20分鐘。
建議票券箱根周遊券 新宿版2日券（大人¥6,100、兒童¥1,100），涵蓋登山電車、纜車、海賊船、巴士等8種交通
浪漫特快另補特急券約¥1,200（免基本車票費）

行程時間軸（早出晚歸）

  • 早出錦絲町出發 → 新宿轉乘浪漫特快
  • 上午抵達箱根湯本 → 轉登山電車到強羅
  • 中午早雲山纜車 → 大涌谷（吃黑蛋）
  • 下午蘆之湖海賊船 → 箱根神社（水上鳥居）體力吃緊時，箱根神社或雕刻之森美術館可擇一割捨，優先保留大涌谷＋海賊船
  • 傍晚回箱根湯本逛商店街 → 浪漫特快返回新宿
  • 晚餐eggslut 或 牛たんの檸檬（新宿分店）
D5

10/9（五）橫濱一日遊

交通

錦絲町 → 石川町：搭JR總武線接京濱東北・根岸線，較原先「上野直達」多一段轉乘，請預留轉乘緩衝時間。

行程時間軸

  • 上午抵達石川町站，步行至中華街
  • 中華街逛街、早午餐
  • 午後山下公園散步（看港口、冰川丸號郵輪）
  • 午後～下午ワンダリア横浜（Wonderia橫濱）— BASEGATE橫濱關內 Tower 3F・4F2026年3月新開幕沉浸式數位藝術體驗設施，森林、深海等6大主題區；成人票約¥2,900起，建議停留1.5-2小時。從關內站步行1分鐘，中華街步行約15-20分或轉乘1站可達；此站會拉長行程，建議視體力與時間，二擇一取代下方「紅磚倉庫」或「合味道紀念館」
  • 下午紅磚倉庫，逛文創市集若女兒對麵包超人有興趣，橫濱麵包超人兒童博物館可取代此站；若排了ワンダリア横浜，此站可省略
  • 傍晚港未來：合味道紀念館 或 橫濱地標大廈68樓Sky Garden看夕陽
  • 夜晚CosmoWorld摩天輪（點燈拍照）
  • 回程橫濱站搭JR返回錦絲町
ワンダリア横浜是2026年才開幕的新景點，行程尚未實測時間分配，建議出發前再依當天體力決定是否排入、要犧牲哪一站。
D6

10/10（六）澀谷・原宿（連假起）

行程時間軸

  • 午餐俺流塩らーめん（近表參道）

10/11（日）銀座・東京車站・六本木美食日

行程時間軸

  • 上午銀座逛街可安排築地場外市場早餐／海鮮
  • 午餐／晚餐候選東京壽司、鰻ひつまぶし備長、喜助、麵屋武蔵 虎嘯連假期間人潮較多，熱門店家建議事先訂位

此日行程方向已定案為「銀座／東京車站／六本木美食路線」，取代原本的迪士尼／台場／teamLab方案。
